Privacy Policy

Instagram Automation Bot — NJTechStudio

What this app does

This app connects to your Instagram Professional account via the Instagram Graph API to receive webhook notifications for comments on your posts/reels and direct messages.

What data we receive

  • Comment text, commenter's Instagram username and user ID
  • Direct message text and sender's Instagram user ID
  • Related metadata sent by Meta's webhook (e.g. media ID, timestamps)

How we use this data

Data received from webhooks is only displayed on this app's own monitoring dashboard, for debugging and visibility purposes. We do not use this data for advertising, profiling, automated replies, or any other purpose.

How we store this data

Recent webhook events and server logs are kept temporarily in memory for monitoring purposes (visible only on this server's own dashboard) and are automatically cleared when the server restarts. We do not persist this data to a database, and we do not sell or share it with any third party.

Data retention & deletion

Since no data is persisted to permanent storage, there is nothing to retain beyond a server restart. If you have questions about any data processed by this app, contact us using the details below.
